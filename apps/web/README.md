# Web app

Frontend/UI-only application.

## Responsibilities

- Dashboard
- Settings
- Automation setup
- Agent workspace
- Live browser view
- Video queue
- Scheduler UI
- Notifications
- Voice command UI
- Agent chat
- Analytics

## Constraints

- No FFmpeg execution
- No long-running provider jobs
- No direct access to persistent business logic beyond API calls
- No direct third-party SDK usage
