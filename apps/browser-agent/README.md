# Browser agent

Isolated Chromium/Playwright automation service.

## Responsibilities

- Chromium
- Playwright
- Browser contexts
- Sessions
- Navigation
- Clicking
- Typing
- File upload/download
- Screenshots
- Browser state
- Third-party website interaction

## Constraints

- Not the owner of business logic
- Receives tasks from the AI orchestrator or API layer
- Stays narrow and deterministic around browser operations
